# User Guide

## 1. Getting Started
Open the Global Connect application and create an account or log in to an existing account.

## 2. Profile
Users can view and update supported profile information through the profile area.

## 3. Connections
Use the connection/discovery features to find users and manage connection requests.

## 4. Feed
Use the feed to view available posts and create supported content.

## 5. Messaging
Open Messages to select a conversation and exchange messages with authorized users.

## 6. Jobs
Use the Jobs section to search or interact with available job-related information.

## 7. Notifications
Check Notifications for updates related to supported account and social activities.

## 8. Account Security
- Keep credentials private.
- Do not share authentication tokens.
- Log out from shared devices.
- Report suspicious activity through the available process.
