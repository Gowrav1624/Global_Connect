# User Acceptance Testing Checklist

## 1. Authentication
- [ ] Registration works
- [ ] Login works
- [ ] Invalid credentials are rejected
- [ ] Protected pages require authentication
- [ ] OAuth works where enabled

## 2. Profile and Connections
- [ ] Profile can be viewed
- [ ] Profile can be updated
- [ ] Users can discover other users
- [ ] Connection requests work
- [ ] Connection status is correct

## 3. Feed and Posts
- [ ] Feed loads correctly
- [ ] Valid posts can be created
- [ ] Invalid content is handled appropriately

## 4. Messaging
- [ ] Conversations can be opened
- [ ] Messages can be sent
- [ ] Real-time behavior works as designed

## 5. Jobs and Notifications
- [ ] Job features work according to scope
- [ ] Notifications are generated and displayed

## 6. Administration
- [ ] Admin access is restricted
- [ ] User/content management works
- [ ] Reports can be reviewed

## 7. Deployment
- [ ] Frontend is accessible
- [ ] Backend is accessible
- [ ] Database connection works
- [ ] Production environment variables are configured

## 8. Final Sign-Off
- [ ] No unresolved critical defects
- [ ] Acceptance criteria verified
- [ ] Documentation completed
- [ ] Stakeholder acceptance recorded
