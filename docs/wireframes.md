# Wireframes

## 1. Purpose
This document defines the primary wireframe layouts for the Global Connect application.

## 2. Core Screens

### Login
- Application logo/name
- Email/username field
- Password field
- Login button
- Google OAuth option
- Registration link

### Registration
- Name
- Email
- Password
- Confirm password
- Registration button
- Login link

### Dashboard / Feed
- Navigation bar
- User/profile access
- Search
- Feed posts
- Create-post control
- Notifications
- Messaging access

### Profile
- Profile information
- Profile image
- Bio/about section
- Skills or professional details
- Connection action
- Edit profile option for the owner

### Connections
- Current connections
- Pending requests
- Accept/reject/request actions
- Search/discovery controls

### Messaging
- Conversation list
- Active conversation
- Message input
- Send action
- Real-time message updates

### Jobs
- Job search
- Job cards/list
- Job details
- Relevant action controls

### Notifications
- Notification list
- Read/unread state
- Navigation to related activity

### Admin
- User management
- Reports/moderation
- Administrative actions
- Status information

## 3. Responsive Behavior
Layouts should adapt to desktop and smaller screens while keeping navigation and core actions accessible.
