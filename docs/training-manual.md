# Training Manual

## 1. Purpose
This manual provides basic training for Global Connect users and administrators.

## 2. User Training

### Login
Open the application and enter valid credentials. Use the configured Google OAuth option where available.

### Profile
Open Profile to review or update supported information.

### Connections
Use discovery and connection controls to find users and manage requests.

### Feed
Open the feed to view posts and use the create-post feature when available.

### Messaging
Open Messages, select a conversation, and send messages.

### Jobs
Open Jobs to search or interact with supported job information.

### Notifications
Open Notifications to review account and activity updates.

## 3. Administrator Training
Administrators should learn:
- User management
- Report review
- Content moderation
- Administrative access controls
- Incident escalation

## 4. Security Training
- Never share passwords or authentication tokens.
- Never commit secrets to source control.
- Use authorized accounts only.
- Report suspicious activity promptly.

## 5. Support
For application issues, record the steps that caused the problem, error messages, screenshots/logs where appropriate, and the affected feature.
