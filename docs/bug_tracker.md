# Bug Tracker

## 1. Purpose
The bug tracker records defects discovered during development and testing.

## 2. Severity
- **Critical:** Prevents core operation or creates a severe security/data issue.
- **High:** Major feature is unusable.
- **Medium:** Significant but has a workaround.
- **Low:** Minor functional or presentation issue.

## 3. Status
- Open
- In Progress
- Fixed
- Retest
- Closed
- Deferred

## 4. Bug Register

| ID | Description | Severity | Status | Assigned To | Resolution |
|---|---|---|---|---|---|
| BUG-001 | No baseline defect recorded | Low | Closed | Team | Initial tracker created |

## 5. Required Bug Information
Every defect should include:
- Reproduction steps
- Expected result
- Actual result
- Environment
- Severity
- Screenshots/logs where useful
- Resolution and verification details
