# Administrator Guide

## 1. Purpose
This guide describes administrative responsibilities in Global Connect.

## 2. Access
Administrative features must be available only to authorized administrator accounts.

## 3. User Management
Administrators may, according to implemented functionality:
- View user records
- Review account status
- Perform approved moderation actions
- Manage reported users/content

## 4. Content Moderation
Administrators should review reports and take actions according to the project's moderation rules.

## 5. Security
- Keep administrative credentials secure.
- Do not share administrator tokens.
- Review unusual account or content activity.
- Use the minimum permissions required.

## 6. Incident Handling
Security or abuse incidents should be documented, escalated when necessary, and handled using the project's incident/change procedures.
