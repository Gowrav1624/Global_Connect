# Project Charter

## 1. Project Name
Global Connect

## 2. Project Purpose
Develop a web-based networking platform that combines professional profiles, connections, content sharing, messaging, jobs, notifications, and administrative capabilities.

## 3. Objectives
- Deliver the approved core networking features.
- Provide secure authentication and authorization.
- Provide a maintainable full-stack architecture.
- Deploy the application for real-world browser access.
- Produce complete technical and project documentation.

## 4. Scope Summary
The project includes requirements analysis, design, frontend/backend development, database integration, authentication, testing, deployment, and handover.

## 5. Technology
React/Vite, Node.js/Express, MongoDB/Mongoose, JWT, Google OAuth, Socket.IO, Vercel, and Render.

## 6. Key Stakeholders
Project owner, project manager, developers, designers, testers, administrators, and end users.

## 7. Major Constraints
- Approved scope and resources
- Security and privacy requirements
- Deployment configuration
- Availability of required third-party services

## 8. Success Criteria
The system meets approved requirements, passes required testing, is deployable, and receives stakeholder acceptance.
